# RC3实施范围与验收门槛

目标候选：v0.5.0-rc.3。技术方案已确认；实施和验证进展见[开发记录](development-status.md)，变更见[CHANGELOG](../CHANGELOG.md)。本文不代表候选已发布或所有实机验收已通过。

## 当前范围

- 安装入口采用raw主分支脚本，只下载预构建；默认交互配置与启动，显式版本固定，--install-only只安装。草稿不成为匿名默认目标；公开RC2保持不可变。
- OpenCode合法JSONC使用hujson保留语法和非本软件配置，拒绝无效结构及重复键。Bridge配置有效的部分接入失败不阻断其他来源和服务，报告保留失败。
- Windows原生接入ZCode、Codex/ChatGPT本地任务及Antigravity；WSL用自己的Bridge用户服务与独立来源标识。Tray不管理WSL服务，不建立跨系统接入代理。
- 同一家族复用受管理hook，不重复安装App/CLI入口。桌面捆绑执行器直接探测，不要求额外CLI；Go适配包独立构建，不要求Rust/MSVC，Tray改动仍需原工具链。
- 用户关注的原生事件和可见正文必须补齐；Antigravity App 2.32.1的WSL实测Stop和PostInvocation均未向用户hook提供回答字段，不以内部描述符冒充可用接口，不读历史补正文；子代理、后台记忆维护及宿主后台安全审查按明确身份过滤。普通工具/步骤错误不误报主任务失败，不全量上传思考、用户答案、认证材料或对话历史。
- 手机标题为原生会话名，正文包含友好主机/环境、中文事件类型及本事件内容；缺正文明确提示，不重复状态标题。最终模板文本整体受渠道实测上限约束，原始事件不变。
- Tray默认10分钟无可信真人输入视为离开，0至1440分钟可调，0关闭。可识别的软件注入不保持在场；不记录按键/坐标，不实际锁Windows。锁屏、离开或未知时不累计自动已读；全部Tray不可信在场才按Hub规则推手机。
- 显示器/DPI变化保留窗口显示意图，不自动显示或还原隐藏窗口。消息探针不代替真实RDP验收。

## 术语与边界

Bridge是Agent执行环境的本机接入；Tray是Windows桌面客户端；hook是原生事件调用入口；notify是Codex独立的轮次完成入口，现有notify不能擅自覆盖。有效锁屏状态仅供通知分流，含系统锁屏或离开，不调用系统锁屏。记忆维护指宿主后台提炼/汇总，用户主动修改记忆文件仍是主任务。真实验收指宿主实际产生事件及用户侧实收，不是静态产物、模拟事件或HTTP成功。

Windows命令型hook须遵循实际宿主shell。RC4修订使用固定执行边界和编码参数兼容CMD/PowerShell，拒绝无法安全表达的路径；ZCode继续使用原生参数数组。云端编排任务、其他Windows终端产品和硬件模拟输入不扩大承诺范围。

## 验收与发布

Go至少运行go test -race ./...与go vet ./...；Node使用Volta/pnpm，Python使用uv。覆盖JSONC安装/更新/禁用、部分失败启动、各来源原生内容与恢复、主子/记忆过滤、手机最终文本、离开/注入输入、Windows窗口及跨WSL运行。缺实际能力的项目说明具体原生依据；缺设备条件不得假称通过。

候选流水线必须绑定同一提交的Linux/Windows构建，校验七类平台/来源包、架构、摘要、签名及完整Hub镜像。沿用既有发布公钥，签名索引递增；候选先产出RC3 Release草稿，经使用者明确确认后公开为预发布；不改RC2、不推广latest、不默认升级正式服务或清空数据。Git写操作、正式模板修改与真实测试发送按明确授权范围执行。
