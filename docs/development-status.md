## 复现

常规源码检查不调用在线模型或真实手机；需回环监听权限及锁定依赖。以下从仓库根目录执行：

```sh
pnpm --dir adapters/opencode install --frozen-lockfile --ignore-scripts
pnpm --dir web/hub install --frozen-lockfile --ignore-scripts
bash scripts/build/build.sh
bash scripts/check/check.sh
bash scripts/build/build-targets.sh
uv run --offline --no-project python tests/e2e/codex_native.py
AGENT_PULSE_PACKAGE_SMOKE=1 pnpm --dir adapters/opencode smoke
```

Windows 使用 `scripts/check/check.ps1 -Tray -Integration` 与 `tests/e2e/windows_desktop.py`；容器、真实 Qoder/Antigravity/ZCode 及手机测试的准备、授权和清理规则见[端到端说明](../tests/e2e/README.md)。不在常规复现命令中隐式发送模型请求或手机消息。
